Lorsque l'utilisateur te demande de réviser du code, suis toujours cette structure :
1. **Résumé** : Un court résumé de ce que fait le code.
2. **Problèmes potentiels** : Bugs ou erreurs de logique.
3. **Optimisations** : Comment rendre le code plus propre ou plus rapide.
4. **Conclusion** : Un verdict final.
